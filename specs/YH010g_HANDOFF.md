## 1. 研究課題 (一文)

機関投資家の議決権行使データを「投資家×議案」の意思決定行列として形式化し、議決権行使助言会社 (ISS / Glass Lewis) の複占が生むモノカルチャー度を測定可能量として定義・推定し、その厚生含意をシミュレーションの介入実験で評価する。

## 2. 位置づけ

- YH010 (価格空間の協調 vs モノカルチャー識別) と同一の識別問題の別ドメイン。共通: 低ランク相関の生成メカニズム分解、介入応答識別、プロビナンス規約。
- 差分: (i) 行動がカテゴリカル (賛/否/棄権) で欠測が情報的、(ii) 実データが公開されており行列が実構成可能 (日本 2017 年以降)、(iii) 「共有地図」が実在の商用主体 (助言会社ポリシー) で、その改訂・分裂が自然実験を提供する。
- 先行研究との関係 (新規性の境界線):
  - 理想点推定は既出: Bolton, Li, Ravina & Rosenthal (JFE 2020) が W-NOMINATE を米ファンド投票に適用、Bubb & Catan (RFS 2022) が「政党」構造を抽出。空間の構成自体は貢献にならない。
  - 助言会社の影響力実証も既出 (Malenko & Shen 2016 の RDD 等)。
  - 空白 = (a) K-R モノカルチャー形式論での再定式化と厚生評価、(b) 共通情報と共有地図の相関分離の識別戦略、(c) LLM エージェントによる介入実験装置。この3点以外に工数を使わないこと。

## 3. 形式化 (実装の正本)

- 意思決定行列 A ∈ {+1, −1, 0, NA}^{N×P}。行 = 運用機関、列 = 議案 (総会×議案番号)。
- 階層因子モデル: a_ij = μ_j + Σ_k λ_ik f_jk + ε_ij
  - μ_j: 議案の共通ファンダメンタルズ (議案属性で条件付け)
  - f: 共有地図因子 (助言ポリシー)。λ_ik: 機関 i の地図 k への追随度
  - モノカルチャー指標 := μ 条件付け後の f 因子の分散シェア (共有エンジンの単一定義を使用)
- 推定バックエンド (共有エンジン `FactorModel`):
  - ルートA: 中心化 + 低ランク分解 (ロジスティック PCA / 行列補完)。回転不定性 → varimax 等の規約を config で固定し、因子の命名は外部照合 (§5 ID-g1) でのみ行う
  - ルートB: 2パラメータ IRT / 理想点 (ベイズ推定)。尺度・回転・鏡映の識別制約を明示
- 欠測: 保有銘柄のみ投票するため MNAR。第一段階は保有で条件付け (保有データと結合し、保有あり×投票なしを棄権系として別コード化)。行列補完的な欠測補間は行わない (非目標 §8)。

## 4. ワークストリーム A — 実証: 日本データパイプライン

### A-1. 行使結果の収集 (最初の資産)

- 対象: 日本の主要運用機関の個別議案ベース行使結果 (2017 スチュワードシップ・コード改訂以降、各社ウェブサイトで公表。中央リポジトリなし)。
- パイロット範囲: まず 2〜3 社 × 直近 2 総会シーズンに限定し、行列が組めることを確認してからスケール (本体決定はパイロット後)。
- 実装: 会社ごとにフォーマットが異なる (Excel / PDF / HTML)。路線価パイプラインと同型の 取得→表構造正規化→スキーマ統一。会社別パーサを分離し、パーサ単体テストに実ファイルのフィクスチャを置く。
- 名寄せ: 発行体は証券コード、議案は (総会ID, 議案番号, 議案分類) で正規化。議案分類は [要記入: 分類体系。ICJ/商用分類を使わない場合は自作ラベル体系を定義]。

### A-2. 議案メタデータ

- EDINET 臨時報告書から議案テキスト・賛成率を取得。μ_j の条件付け変数 (議案類型、ROE、政策保有比率などの発行体属性) を構築。

### A-3. 助言推奨の代理変数

- 商用データ (ISS Voting Analytics) は前提としない。両社の公開ポリシーから推奨を規則ベースで再構成 (例: ISS 日本基準の ROE 5% 閾値、政策保有比率基準 → 該当議案に反対推奨フラグ)。
- 再構成器はポリシー年度でバージョン管理 (ポリシー改訂 = 識別に使う介入時点なので、年度の取り違えは致命的)。
- 精度検証: 推奨が報道等で判明している著名議案 [要記入: 検証セット] で照合。

## 5. ワークストリーム B — シミュレータ: ガバナンス介入実験

- YH010 サンドボックスのフォークとして実装 (Task 0 完了後)。市場エンジンを総会エンジンに差し替える: 主体 = {投資家エージェント, 助言者 (ポリシーエンジン), 発行体}、インスタンス = 議案、行動 = 投票。
- 助言者はルールベース (公開ポリシーの再構成器を流用)。投資家は {完全追随 / 閾値追随 / 独立判断 (LLM または規則)} の混成。
- 宣言的介入 (共有 `Intervention` API):
  - IV-1 助言相関の操作: 助言者数 (1/2/k 社)、ポリシー重複度をパラメータ化 → 決議結果分布とモノカルチャー指標の応答
  - IV-2 マンデート不完備度: 委任連鎖 (アセットオーナー→運用機関) の指示の粗さを操作 → 選好の透過率
  - IV-3 エンゲージメント vs ダイベストメント (第二スプリント以降。初回スコープ外)
- 識別器 (実データ側と共通):
  - ID-g1 推奨分裂: ISS と GL の推奨が割れた議案 = 地図因子だけが動く変動。因子命名の外部照合にも使用
  - ID-g2 ポリシー改訂イベントスタディ: 改訂日前後で μ を固定し f の変化を捕捉
  - ID-g3 閾値 RDD: ポリシー閾値 (ROE 5% 等) 近傍の発行体で局所比較
- TwinMarket 禁止則: 「それらしい総会が再現できた」は成果ではない。全ての実験は介入→応答→識別の三つ組で事前登録し、様式化事実の一致のみを根拠とする主張を論文・README に書かないこと。

## 6. 統計処理

- モノカルチャー指標の時系列 (年度別推定) とその信頼区間 (機関単位ブートストラップ)。
- クラスタ構造: 負荷ベクトルのクラスタリングと収縮度の時間変化 (埋め込み図はここから生成)。
- 実データとシミュレータの突き合わせ: シミュレータの助言相関パラメータを実データの推定値に合わせた上で、IV-1 の反実仮想 (助言 1 社化 / k 社化) の厚生比較を行う。
- 厚生関数 (2026-07-23 ユーザー決定): **両方を報告し、主 = 決議の情報集約効率、従 = K-R 型選択品質**。根拠: 議決権行使は票が議案ごとに単一決議へ集約される構造を持ち、モノカルチャーの害は「実効的な独立票数の減少」(相関下でのコンドルセ陪審定理の劣化、Ladha 1992 系が形式化の土台) として現れる — 厚生の自然な単位は決議の質。K-R 型は YH010 (価格空間)・モノカルチャー文献との比較可能性のための従指標。両指標の形式的定義は理論節で固定し、共有エンジンのモノカルチャー指標 (§3) とは区別して実装する。
