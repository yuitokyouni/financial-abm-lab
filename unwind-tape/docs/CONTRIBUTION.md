## 1. Contribution claim（1文 + 最終成果物）

政策保有株の“処分”では、売り手(銀行・事業会社など)が**売出し・立会外分売・ToSTNeT-3 などの「売却方式」を自分で選ぶ**。安く・目立たずさばける方式を選ぶので、**方式の選び方それ自体がコストを左右する**。

> **主張(1文)**: 本研究は、政策保有株処分の実損を、**(a)** どの売却方式で市場に出したかの**“選び方”まで含めて**捉え(方式を外から決め打ちにしない)、**(b)** 発表日を開示時刻から厳密に定めた**自作の解消イベント台帳**の上で、**方式ごとの実損の内訳(s1=発表 / s2=ドリフト / s3=執行)を実データから測り**、**(c)** その**方式ごと・規模ごとのコスト分布の違い**を再現できるかでモデルの当否を判断する(汎用の“市場っぽさ”= stylized facts の再現では判断しない)点で、既存の単一方式の価格形成モデル・最適執行・イベントスタディのいずれとも異なる。

### 最終成果物（これを出す）

1. **実損分解テーブル** ── 各解消イベントの `s1`(発表)/ `s2`(ドリフト)/ `s3`(執行)/ `IS_adj` を、**売却方式・規模(size/ADV)つき**で並べた実データ台帳。「発表で下がったのか、さばき方で損したのか」が1行で読める形。
2. **非線形の実証** ── 標準TCA(√・size/ADV)の予測と**実測 IS のズレ**を、規模の関数として示す図・数値。平時の**参照分布の裾**を重ね、「どの規模からズレるか」を経験的に示す。
3. **吸収・ルーティング ABM** ── 売り手の**方式選択**と、**方式ごとの条件付きコスト分布**を再現する計算模型。標準TCA が外す非線形領域を、模型のパラメータ(どの規模・流動性でコストが跳ねるか)で説明する。
4. **レポート / 論文** ── 上記をまとめ、政策保有処分の実損分解と非線形領域の ABM 説明を主張する。

過大主張はしない(「世界初」等は用いない)。足すのは (a)(b)(c) と上記4成果物であり、それ以外(生成機構の同定・汎用性)は主張しない。

**方法論的接続(PROV-ABM)と、その正確な射程**: 「stylized facts の再現では機構を分けられない、**応答で分ける**」という Intervention Atlas / PROV-ABM の立場(`imported/PROV-ABM-atlas/CLAUDE.md`、`docs/working_paper_identification_obstacle_v0.md`)を、YH009 は**検証哲学として**借りる。ただし ── **ここが前案の誤りの訂正** ── PROV-ABM の言う「介入(intervention)」は**模型の中で外から動かすツマミ**(tick size、batch interval 等)であって、**売り手が自分で最適に選ぶ売却方式(内生の意思決定)ではない**。よって:
- **模型側**: ベニュー可用性・買い手のリスク枠・開示制度などを**外生に動かして**分布がどう動くかを見る = これは正当に「介入への応答」。
- **実データ側**: 売却方式は**選択(内生)**であって介入ではない。実データでは方式・規模を**条件**として条件付き分布を比較する(介入ではなく条件付け)。
- PROV-ABM の scope(`program_claims_v1.md §0`:「実データからの機構同定は主張しない」)を継承し、**識別対象は生成機構でなく、条件付き分布の(方式・規模に対する)形**に留める。

## 3. 退化経路（Degradation paths）— 不変条件

以下3つが揃うと本研究は既存の下位互換に退化する。設計判断のたびに照合する**不変条件**。

- **D1 — 売却方式の選択を落とし、単一方式に固定する**
  - 許容(一時): 初期プロトタイプで単一方式(例: `secondary_offering`)に絞って配管を通す。
  - 不可(恒久): 方式選択を外生固定したまま「コスト分布を説明した」と主張すること(差分表**研究対象**行の全列を毀損、C1/C4 の下位互換へ退化)。
- **D2 — 台帳の N 不足を理由に、汎用 stylized facts 適合へ回帰する**
  - 許容(一時): N ゲート未達の間、配管検証のため SF 的整合チェックを**補助的に**使う(主張には使わない)。
  - 不可(恒久): measurable legs の N を満たさぬまま SF 適合を**検証の主軸**に据えること(Simudyne① / PRISM の死因の再演、**検証のしかた**行を毀損)。
- **D3 — 分布の“違い”の検証を後回しにする**
  - 許容(一時): 初期は分布の**記述**(参照分布・方式別 s3)を先に出し、方式間・規模間の違いの検証を次段に置く。
  - 不可(恒久): 違いの検証を実装せずに「説明した」と結論すること(誘導形イベントスタディ C5 と区別がつかなくなる)。

## 4. 正直性の但し書き

- **s2 の解釈限界**: 日次データで観測できるのは**価格ドリフトのみ**。先回り・ヘッジ・需要退避・インデックス調整の**メカニズム帰属は識別できない**。標的は「**参加率の関数としての分布の形**」であって、s2 に単一機構を割り当てない。
- **N ゲート未達の間は経験的主張をしない**: `measurable execution legs >= 30、かつ主要な売却方式 2系統以上で各 10 leg 以上`(`BENCHMARK_SPEC.md` §N ゲート)。未達の間は記述・配管のみ。
- **s3 の方式間の単純比較は禁止**(spec 凍結、`MEASUREMENT_SPEC.md`)。方式間の比較は `IS_adj` で行う。本書の主張(特に (c) の「分布の違い」)はこれと矛盾しない ── 方式を**条件**として扱い、s3 単体を方式横断で比較しない。
- **(補・前案の訂正)** 売り手の売却方式選択を「(準)介入」、その効果を「介入への応答」と書いたのは**誤り**。介入は外生の操作を指し、売り手が最適に選ぶ内生の意思決定は介入ではない。「介入 / 応答」の語は**模型内の外生操作に対してのみ**用い、実データ上の方式選択には用いない(=条件付け)。
- **(要人間判断)** 上記の言い換え後も、「検証」の語が模型の当否判定を超えて生成機構の同定を含意しないか、要確認(§末尾に回す)。

## spec 整合性の確認 / spec 矛盾の疑い（人間の判断に回す）

凍結 spec の定義(`s1/s2/s3`・`IS_raw/IS_adj`・N ゲート・`measurable_flag`・`sale_route` 別定義・s3 方式間比較禁止)は**一切変更・再解釈していない**。現時点で**明確な矛盾は検出していない**。人間判断が要る論点を2つ挙げる:

1. **層の区別(矛盾ではないが誤読注意)**: 凍結 spec は**測定層**で売却方式を**所与**として方式別に実損を測る。本 claim (a) は**説明層**で方式選択を**モデルに入れる**。両者は矛盾せず、測定層の方式別 s1/s2/s3 分布が説明層(方式選択 ABM)の**答え合わせ用の実測値**になる、という補完関係。設計時にこの層を混同しないこと。
2. **「検証」の語の射程(要確認)**: PROV-ABM の応答による識別は synthetic・GT 既知で確立。YH009 は実データで、方式・規模を条件とした条件付き分布の比較に留める(生成機構の同定には及ばない)。この語法を承認するか、より弱い語(「特徴づけ」等)に置換するかは人間判断。
