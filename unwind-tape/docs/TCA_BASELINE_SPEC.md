# TCA ベースライン仕様 v0.1（提案・要ユーザ確定）

**目的**: CONTRIBUTION 成果物② の「非線形の実証」= `実測コスト − 標準TCA予測` を測るための、
**引く相手(標準TCAの予測)を、データが揃う前に定義**する。閾値・関数形・比較対象を後から選ぶと
p-hack になるため、PREREG に凍結する前提の**提案**。決定が要る箇所は ★要確定★ を付す。

---

## 1. 何を予測し、何と比べるか

> **用語の注意(重要)**: 測定(系統B / `shortfall_engine`)は**常に s1・s2・s3 を全部測って保持**する
> (`IS_raw = s1+s2+s3` は毎回そのまま)。本節の「比較対象 = s2+s3」は、**成果物②の非線形残差で √予測から
> “引かれるデータ側の量”**を指すだけで、s1 を測らない/捨てる意味ではない。s1(発表の情報効果)は
> 系統A(CAR)で別途扱う。また②の比較は **実測(s2+s3) vs 標準TCA(√)の理論予測**であり、**ABM ではない**
> ── ABM は成果物③で、②が確定した残差(実測分布)を**再現**する側として後から登場する。

- 標準TCA(√則)が予測するのは**執行(流動性)コスト**であって、**情報効果 s1(発表インパクト)ではない**。
- **比較対象 = 執行+ドリフト = `s2 + s3`**(2026-07-09 ユーザ確定)。s1 を残差のデータ側に混ぜると、
  √則が予測していない情報効果で残差が水増しされるため除外。s1 は測定・保持し系統Aで使う。
  - 参考(不採用): `s3` のみ / `IS_adj` 全体(s1込み)。
  - **spec 遵守**: 残差の**方式(sale_route)横断比較は `IS_adj` で行い、生の `s3` を方式横断で比較しない**
    (MEASUREMENT_SPEC 凍結)。方式ごと(within-method)の残差か、`IS_adj` ベースで比較する。

## 2. 関数形(平方根則)

```
C_hat = Y · σ · sqrt(Q / V)          # 予測執行コスト(log 単位で s2+s3 と整合)
```
- `Q` = 執行サイズ(株数、または代金)。leg の `sold_shares` / `executed_shares`。
- `V` = ADV20(既存 `car_engine.compute_adv` を再利用)。
- `Q / V` = participation ratio ── **ベンチ v0.2 の size/ADV20 軸と同一**にする(残差を同じ横軸で読む)。
- `σ` = 事前窓の日次 log-return ボラティリティ。 ★要確定★(car_engine の推定窓 [-140,-21] を流用するか、
  イベント直前の短窓にするか)。
- `Y` = インパクト係数(次節で決める)。

## 3. 係数と「相転移点」の決め方 ── 決め打たず、推定する（本仕様の核心）

**相転移点(√則が破れる折れ点)は固定閾値で決め打たない。データから推定する(=キャリブレーション)。**
人間が閾値を先に引くと「一番知りたい答え(どこで壊れるか)」を埋め込む p-hack になるため。

- **主手法 — segmented / changepoint 回帰**: √係数 `Y` と 折れ点 `τ` を**同時推定**する。
  小 side は `cost ≈ Y·σ·√(Q/V)`、`τ` 超で追加の非線形項、として **τ を自由パラメータで推定**し、
  **τ に信頼区間**を付ける。固定閾値は宣言しない。
- **頑健性 — べき乗**: `cost ≈ Y·σ·(Q/V)^α` を当て、**α > 0.5(super-√)か**を検定。α もデータ推定。
- **非線形残差**: `Δ = 実測(s2+s3) − C_hat`。記述段階では size/ADV20 バケット別に `Δ` を並べて可視化
  (相転移の主張はしない)。推定段階で `τ` / `α` を出す。
- **事前登録するのは“数値(τ)”でなく“推定器(手法)”**: segmented 回帰の定義・τ の CI の出し方・
  robustness の α ── **手法だけ**を PREREG に凍結し、criterion-shopping を封じる。相転移点そのものは
  結果として出る(手で置かない)。
- **N 依存**: `τ` の推定は**両側(小 side / 大 side)にサンプル**が要る。N ゲート(≥30、主要方式2系統×
  各10)未満は**記述のみ、τ を主張しない**。

> **用語(平易版)**:
> - **leg** = 個別の売り1件(売り手 × 方式 × 執行)。例:任天堂で「野村信託が売出しで売った」= 1 leg。
> - **group** = 1銘柄の解消イベント(その legs を束ねたもの)。例:G008 = 任天堂の解消 = 2 legs(売出し + DeNA の ToSTNeT-3)。
> - **s1 は銘柄イベント単位** = 発表1回につき1個(全売り手が同じ下落を共有)。s2/s3 は執行(leg)ごと。
> - **C_hat**(シー・ハット、`^`)= √則モデルが予測した執行コスト。実測との差 `Δ = 実測(s2+s3) − C_hat`。

## 4. トランシェ(分割解消)の扱い ── ユーザ指摘の反映

売り手は**分割で1回当たり size を下げ、線形域に留まる**。よって:
- **線形域のサンプルは主にトランシェ/小口**、**非線形域は“分割しきれない/急いだ強制大口”**。この対比が
  非線形の起点を炙り出す(分割で回避できなくなった所で√則が破れる)。
- **単位**: √則は**執行単位(子 leg)に当てるのを主**とする。親(=同じ day0 を共有するグループ)単位の
  総コストは記述用のロールアップとして併記。**leg 別 `C_hat` と group 集計の両方を保存**。
- **集計規則(既定・当たり前ルール)**: `s1` は**銘柄イベント単位**の量(発表は親で1回、全売り手が同じ
  day0 を共有)、`s2/s3` は**執行単位(leg)**の量。よって group 総額 = **`s1`(1回)+ `Σ_leg (s2+s3)`**。
  これで s1 の二重計上は起きない(特別な処理は不要)。
- **多年・別発表の分割解消**は**別グループ(別 day0・別 s1)= 独立イベント**なので合算対象でない。
  保有者の多年トータルを出す場合は s1 が別イベントの合算になるため**別集計**(単純合算しない)。

## 5. 補助ベースライン(経験的)── 理論と実測の両にらみ

√則(理論)に加え、**ベンチ v0.2 の参照分布(`off_both × discount`)の中央値・裾**を、size/ADV20
バケット別の「**平時の実測ベースライン**」として併置する。
- 理論外挿(√則)からの残差 と、実測平時(参照分布)からの残差 の**両方**で非線形を見る。
- 参照分布は**無帰属(tape 非混入)**のまま対照として使う(BENCHMARK_SPEC 遵守)。

## 6. 入力の測定(既存エンジン再利用)

| 記号 | 量 | 取得元 |
|---|---|---|
| `Q` | 執行サイズ | legs.csv `sold_shares` / `executed_shares` |
| `V` | ADV20 | `car_engine.compute_adv`(生 or 調整出来高は要統一。参照分布側と揃える) |
| `σ` | 日次 vol | 事前窓の log-return 標準偏差。**主 = 直前60営業日(確定)**。窓は config パラメータ化し {20,60,140} をロバストネスで掃く |

> **窓(ADV/σ)の運用**: 窓長は較正対象ではないが、後で {20,60,140} を掃いて頑健性を見る前提で
> **すべて config パラメータ化**する(ハードコードしない)。そのため**価格履歴は ≥140営業日+バッファ
> を先に取得**しておき、窓を変えるたびの再取得を不要にする(既存 J-Quants 取得は 2022-07-01 起点で
> 帰属 leg 分は充足済み)。
| side | 売り/買い | ベンチの `side_proxy` と同規約で売り側に符号を揃える |

## 7. 事前登録フック(PREREG へ)

N を増やす**前に**凍結する項目: **関数形(√)・比較対象(`s2+s3`)・相転移点の推定器(segmented 回帰 /
べき乗 α)・残差メトリック・side 規約・σ 窓**。**凍結するのは推定“手法”であり、相転移点の“値 τ”は
凍結しない(推定する)**。以後 criterion-shopping しない。

## 8. N ゲート(主張の保留)

本ベースラインでの**非線形残差の経験的主張は、`measurable legs ≥ 30`(主要方式2系統×各10)まで保留**
(BENCHMARK_SPEC §N ゲート / CONTRIBUTION §4)。それまでは記述・配管・単発事例の図示のみ。
