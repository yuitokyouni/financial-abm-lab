### B. モデル・市場環境

| 語 | 解説 |
|---|---|
| **SG / Speculation Game** | Katahira & Chen (2019) の投機市場エージェントベースモデル。口座残高 \(w\) が注文サイズ \(q=\lfloor w/B\rfloor\) に連動する。中核主張の一つが **ファネル構造**。 |
| **Katahira-Chen** | 上記 SG 原論文系列の呼び方（論文1: Physica A 524、論文2: arXiv:1909.03185、論文3: 自己組織化版）。 |
| **LOB** | Limit Order Book（指値注文板）。現実の取引所に近い連続ダブルオークション。スプレッド・スリッページ・約定不確実性がある。 |
| **PAMS** | Platform for Agent-based Market Simulation（Hirano & Izumi 2023）。本研究の LOB 実装基盤。 |
| **aggregate / agg** | LOB なしの集計需要型価格更新（\(\Delta p = D/N\)）。注文が即座に価格へ反映される「理想化された」世界。YH005 系の標準環境。 |
| **MMFCN** | Market Making FCN agent。PAMS 上で流動性（指値）を供給する外部エージェント（通常 30 体）。いないと SG の成行が約定しにくい。 |
| **FCN** | Fundamental / Chart / Noise を統合したトレーダ型。MMFCN の母型。 |
| **認知閾値 C / c_ticks** | 価格変動を「シグナル」と認める最低幅。aggregate では \(C=3.0\)、LOB では tick 換算の **c_ticks≈28**（\(3\times\mathrm{median}|\Delta\mathrm{mid}|\)）。**trigger 律速**の鍵。 |
| **stylized facts** | 実市場リターンに共通する経験則（厚い裾・ボラティリティ・クラスタリング等）。SG 再現の評価軸（Cont 2001 由来）。 |
| **ABM** | Agent-Based Model。多数のルール駆動エージェントで市場をシミュレートする枠組み。YH001–008 の主戦術（YH009 は実データ）。 |

### C. ファネル・条件・仮説

| 語 | 解説 |
|---|---|
| **ファネル / funnel 構造** | 「長い **round-trip** ほど損益 \(\|\Delta G\|\) のばらつきが広がる」漏斗型の構造。SG では資産格差・大口注文の帰結として語られることが多い。 |
| **F1** | Funnel 1。Phase 1 で見た「LOB では Pareto 初期資産がファネルを弱めるが、aggregate ではほぼ弱めない」という **world×wealth 交互作用**そのもの。後に ensemble では interaction≈0（null）と確定。 |
| **interaction** | 差の差 \((C3-C2)-(C0p-C0u)\)。LOB での Pareto 効果が aggregate での Pareto 効果からどれだけズレるか。F1 の操作的定義。 |
| **Pareto（初期資産）** | 初期 wealth を Pareto（\(\alpha=1.5\)）で与える条件軸。現実再現そのものが目的ではなく、「LOB 摩擦下で wealth が流れるか残るか」を試す probe。 |
| **Uniform** | 初期 wealth が均一な対照条件（記号末尾 `u`）。 |
| **仮説 A（単純版）** | q-pollution 仮説。LOB で agent が長生き → 初期 Pareto が残る → \(q=\lfloor w/B\rfloor\) 経由で注文サイズ異質性が残り → ファネルを汚染する、という連鎖。 |
| **仮説 A revised** | A1 後の改訂版。単純な q 経路ではなく、「Pareto LOB では **凍結**により初期 wealth が **refresh** されず **persist** し、その wealth-tail がファネル減衰の主因」とする。S6（A3）で直接検証。 |
| **q / q heterogeneity** | \(q=\lfloor w/B\rfloor\)。wealth 依存の注文サイズとそのばらつき。仮説 A 単純版の因果経路の核心。 |
| **C0u / C0p / C2 / C3** | 実験条件。C=Condition。0=aggregate、2/3=LOB。末尾 u=Uniform、p=Pareto。**C3**（LOB+Pareto）が主観察条件。 |
| **C2_A1 / C3_A1 / C3_A3** | 上記に ablation を付けた条件。`_A1`=q 固定、`_A3`=寿命上限。 |
| **A1 ablation** | 全 agent の \(q\) を定数に固定し、wealth→注文サイズ経路を遮断する操作実験。 |
| **A3 ablation** | agent が \(\tau_{\max}\) 生存したら強制交代し、長寿命・wealth persistence を人為解除する操作実験。 |
| **ablation** | モデルの一部を意図的に切って因果経路を特定する実験手法。本研究では A1 と A3 のみ（A2 は無い）。 |

### D. 生存・凍結・hazard

| 語 | 解説 |
|---|---|
| **RT / round_trip** | open→close の 1 往復取引。horizon \(h\) と損益 \(\Delta G\) の単位。**agent の市場滞在 lifetime とは別物**。 |
| **survival gap** | aggregate と LOB で agent の生き残り方（退場率・残存率）が大きく違う発見候補。 |
| **LOB censoring** | シミュレーション終了時点でまだ退場していない agent の割合。LOB で高い（例: raw 約 81% vs agg 0.9%）。シミュレーション長 \(T\) の差を含むため、**raw 比較は retire** し matched KM を正とする。 |
| **matched KM S(τ)** | 窓長を揃えた（matched）Kaplan–Meier 生存関数。出生から退場までの残存確率。 |
| **hazard** | 単位時間あたりの退場率。agg は **ramp→steady**、LOB は **shake-out** 後にほぼ 0（凍結）。 |
| **ramp→steady** | aggregate の hazard 形。初期は低く、wealth buffer 消化後に約 \(3\times10^{-3}/\mathrm{step}\) で定常化し、cohort が絶滅へ向かう。 |
| **shake-out** | LOB 初期（\(\tau\lesssim250\)）の高 hazard 帯。特に C3 で Pareto 下位を洗い流し、その後凍結。 |
| **凍結 / frozen / H_frozen** | LOB で初期 shake-out 後、hazard が検出限界以下になり agent がほぼ退場しない状態。**H_frozen** は「これは有限 \(T\) の artifact ではない」という仮説（S5.8 で確定）。 |
| **refresh / persist** | aggregate では交代で初期資産が洗い流される（refresh）。LOB 凍結では初期分布が最後まで残る（persist）。仮説 A revised の中核。 |
| **Layer-2-timescale** | 「LOB の \(T=1500\) は Katahira の \(T=50000\) の 1/33 で短すぎる」という留保。S5.8 で凍結が解けないと実証され、手振りから測定済み結果へ格上げ。 |
| **lifetime cap / τ_max / LifetimeCapSpeculationAgent** | A3 の実装。在籍 \(\tau_{\max}\)（較正例=121）で強制交代する agent サブクラス。 |
| **agent-steps** | リスク集合の累積暴露量（at-risk agent × 時間）。S5.8 では延長区間で約 5.09M agent-steps・退場 0 件と報告。 |
| **H_micro** | 「LOB でファネルが浅いのはサンプル数差ではなく microstructure の真効果」仮説。S5.5 で強支持。 |

### E. 指標・方法論・ステージ

| 語 | 解説 |
|---|---|
| **bin_var_slope** | horizon \(h\) を log 等間隔ビンに分け、各ビンの \(\mathrm{Var}(\log\|\Delta G\|)\) と \(h\) の傾き。ファネル本体の直接指標。**headline の主指標 1 本**。 |
| **orderVolume 弾力 ε** | MMFCN の注文量を変えたときの RT 数の弾力性。\(\varepsilon(4x)=0.254\le0.3\) なら MMFCN は副次的供給源で、artifact 説を棄却。 |
| **ensemble** | 複数独立 seed（通常 100 trial）で平均・bootstrap CI を取る設計。単 trial の偶然を排除。 |
| **KPI / L3 判定** | 成功基準レベル L1–L4。**L3** は A3 後の成功判定（interaction の部分縮小＋中間予測の整合など）。 |
| **determinism guard** | 同一 seed で独立 2 回実行し、bit/意味一致を確認してから ensemble に入る再現性チェック。 |
| **bit-parity** | 参照実装と変更後で RNG 消費順込みの結果が bit 一致すること。後方互換の契約。 |
| **smoke** | 短縮設定での配線確認（q 固定や lifetime cap が動くこと等）。ensemble 前の必須ゲート。 |
| **pre-registered** | 結果を見る前に判定閾値・dead zone を plan に固定すること。 |
| **matched estimand** | 条件間比較で窓・サンプルサイズ等を揃えた推定量。raw censoring → matched KM 置換が典型。 |
| **headline 規約** | proposal/口頭用の言い方ルール。raw censoring は retire；主 headline は hazard 構造；funnel は bin_var_slope 1 本；数字に対象物ラベル必須。 |
| **dossier** | `YH006_research_dossier.md`。経緯・確定数値・protocol・残課題を proposal 用に一元化した素材。 |
| **S1〜S7 / S5.5〜S5.9** | YH006_1 の段階。S1=再分析、S2=agg ensemble、S3=LOB ensemble、S4–S5=A1、S5.5–S5.8=方法論防御、S5.9=c_ticks 再較正、S6=A3、S7=proposal 素材化。 |
| **P2 / self-consistency** | c_ticks を SG 投入前 regime で較正したため、投入後ボラと自己整合でない残存弱点。S5.9 の対象。 |
| **trigger 律速 / fill 律速** | 凍結・RT 希少の主因が「認知トリガーが低い」（trigger）か「板で約定しにくい」（fill）かの切り分け。YH007 vs 軸2 の優先度を決める。 |
| **軸2** | 執行層導入（大口 \(q\) を TWAP/POV 的に分割執行）という将来介入軸。fill 側を埋めるが trigger 側には効かない。 |
| **zero-fill open** | open 成行が反対板不足などで約定量 0 になる現象（Phase 1 で約 30%）。SG シグナルの一部が LOB で消える artifact。 |
| **Hill α** | 裾指数の Hill 推定量。小さいほど厚い裾。YH007 受け入れ基準の一例。 |
| **\|r\| ACF(50)** | 絶対リターンの自己相関（ラグ 50）。ボラティリティ・クラスタリングの指標。 |

### F. YH008（LLM / mech-interp）

| 語 | 解説 |
|---|---|
| **LLM-as-agent** | LLM を市場参加者として状態を見て売買判断させる枠組み。YH008 では閉ループ市場は Stage 5+ に延期し、single-turn 判断アンサンブルで進める。 |

| **disposition（効果）** | 含み益のとき売りやすく、含み損のとき売りにくい傾向。単一資産では `P(sell\|gain)−P(sell\|loss)>0` を proxy にする。 |
| **clean-probe** | 理由生成をさせず、decision トークン直前の logit だけ読むプローブ。v_ATH 同定・介入の canonical。 |

| **logit ベース抽出** | サンプリングせず、decision 位置の True/False 確率質量から `P(sell)` を読む。 |
| **paired-state** | 参照点（ATH 等）だけを変えた状態ペア。行動差が出たペアだけを v_ATH の教師信号に使う。 |
| **exploration set / held-out** | 事前分割。方向同定は exploration のみ。held-out は Stage 3 ゲートまで温存。 |
| **sec1_faithful** | canonical な clean-probe wording。実装ブリーフに忠実な最小回答指示。 |
| **PASS_STAGE2_LOSS_CONDITIONAL_CONFIRMED** | P0.5 の判定フラグ。「loss 文脈の ATH 非対称が確認できたので Stage 2（loss-conditional v_ATH 同定）へ進んでよい」。Stage 2 本体の完了ではない。 |

## 1. YH006 系（YH006 Phase 1 → YH006_1 Phase 2）— SG の LOB 移植

### 1.1 系譜

研究課題は「**現実的な注文板（LOB）を介した取引は、Speculation Game の資産駆動型市場機構（特にファネル構造＝長い往復取引ほど損益ばらつきが広がる構造）をどう変質させるか**」。

```
YH005 (SG aggregate 最小実装 + 3モデル比較)
  → YH005_1 (3層機構の数値実証、round_trips ログ基盤確立)
    → YH006 Phase 1 (SG を PAMS LOB へ移植、2×2 実験、F1 初観察)
      → YH006_1 Phase 2 (100 trial ensemble 化 + ablation、S1〜S6)
        → (将来) YH006_2 (LIMIT 注文拡張 + 論文 Fig.11/12/13 フル再現)
```

議論の展開は「発見 → 統計的検証 → 発見の置き換え → 方法論攻撃への防御 → 因果検証」という連鎖:

1. **F1 初観察（Phase 1, 単一 seed）**: LOB 化すると初期資産格差（Pareto）がファネルを大幅減衰させる interaction（差の差 \((C3-C2)-(C0p-C0u)\)）≈ −0.27。aggregate（LOB なしの集計需要世界）では起きない。
2. **S1–S3（ensemble 化）**: 100 trial で **F1 interaction は null と確定**（CI が 0 跨ぎ、agg 側 CI 幅 0.003 の精度で「真に null」）。単一 seed の −0.27 は LOB の seed 間分散による noise だった。一方、**marginal な世界効果（LOB ≪ agg のファネル）** は razor-sharp に確定し、副産物として **survival gap**（LOB と agg で agent 生き残り方が大きく違うこと；raw LOB censoring 81.1% vs agg 0.9%）が本物の発見として浮上。
3. **S4–S5（A1 ablation: q = 定数固定）**: **仮説 A 単純版（「q heterogeneity → funnel 汚染」）を反証**。q（wealth 依存注文サイズ）を切ると uniform LOB（C2_A1）は agg 水準へ戻る（−0.31）が、Pareto LOB（C3_A1）は動かない（−0.09）。ここから **仮説 A revised**（「Pareto LOB では agent が凍結し、初期 wealth 分布が refresh されず persist することが funnel 減衰の dominant 因子」）が浮上。
4. **S5.5–S5.8（Yuito の方法論的指摘への防御 4 連戦）**:
   - **S5.5**: 「agg と LOB で RT（round-trip）数が 8 倍違う」指摘 → sub-sample 制御で **H_micro 強支持**（サンプル数差では説明不能＝microstructure 真効果）。
   - **S5.6**: 「MMFCN（流動性供給エージェント）設定の約定 artifact では」指摘 → orderVolume 弾力性 ε(4x)=0.254 で **artifact 説棄却**。
   - **S5.7**: 「censoring 81% vs 0.9% は T 交絡（1500 vs 50000）」指摘 → raw 比較を retire し、matched KM S(τ)（窓揃え Kaplan–Meier）に headline を差し替え。**survival gap は hazard 起源**（agg = ramp→steady ~3e-3/step で cohort 絶滅、LOB = shake-out 後に hazard 凍結）。
   - **S5.8**: 「凍結は有限 T artifact では」→ T=10000 延長で退場 event **0 件** / 5.09M agent-steps、**H_frozen 確定**（h 上限 5.9e-7、閾値の 1/34）。Layer-2-timescale 留保が「測定済み result」に格上げ。

### 1.2 どこで詰まっているか

- **S6（A3 ablation = lifetime cap τ_max=121 で凍結を人為解除）が実行途中で停止**。dossier（2026-06-07 時点）によれば Windows 側実装は完了（hook + `LifetimeCapSpeculationAgent` + τ_max 較正 + parity 27 件 PASS）だが、**Mac 側の C3_A3 × 100 trial（~2–3 時間）が未実行**。`data/C3_A3/` も `stage_S6_diff.md` も存在しないことをリポジトリ上で確認済み。これが仮説 A revised の direct causal test であり、Phase 2 の科学的結論（「凍結 tail を除くと funnel が戻るか」）がここで宙吊りになっている。
- **S5.9（c_ticks self-consistency = 残存 limitation P2 の解消）が Draft・Yuito 承認待ち**。c_ticks=28 は SG 投入前の揺らぎで較正した値で、投入後 regime に self-consistent でない。gap の「大きさ」には効かない主張だが、trigger 律速か fill 律速かの切り分け（＝軸2／YH007 の go/no-go 判断材料）がここに依存。
- **S1-secondary（plan A/B 分岐の bootstrap 最終確定）** も保留（優先度は Yuito 判断）。

### 1.3 今後の予定

1. **S6 完遂**: Mac で C3 等価チェック → A3 smoke → determinism guard → 100 trial → Windows 集計 + KPI L3 判定。pre-registered 判定: C3_A3 の pooled bin_var_slope が C0u/C2_A1 側（−0.31〜−0.40）へシフトすれば**仮説 A revised 確定**、C3 のまま（−0.13）なら fail → S7 で別 mechanism 探索。
