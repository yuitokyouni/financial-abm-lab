## Task 0: 共有エンジン `packages/agora_engine`

| モジュール | 内容 |
|---|---|
| `decision_matrix.py` | `DecisionMatrix`（N×P float行列、NaN=非観測、長形式⇔行列の往復、矛盾重複の検出、lopsided列フィルタ） |
| `factor_model.py` | ルートA `fit_pca_em`（Bubb & Catan 2022のEM型欠測補完PCA。列平均補完→中心化SVD→再補完の反復。回転はSVD主軸固定・符号のみ不定と規約明記）。ルートB `fit_irt` はTask 5スタブ |

### パース中に確定した実データ仕様（目録の補遺）

1. MUFG信託の子議案番号は2024年6月分以前=空欄、2024年7月以降=0 — どちらも0に正規化。データ末尾に「（注）」フッタ行あり（スキップ処理）。
2. アモーヴァの総会日はdatetime型と'YYYYMMDD'文字列が期により混在。シートは24q1まで'JP'単独、25q1以降'個別開示'。
3. ニッセイは総会種類を開示しない。会社ブロック形式のパースはシート内データ行数と完全一致（14,406 / 13,434行）を確認。
4. 証券コードは英数字あり（例: 142A）— 4–5桁英数字として処理。
5. **3社とも賛否の値域は{賛成, 反対}のみ**（賛成\*=不統一行使注記を含む）。棄権・白紙は個別開示に出現せず → HANDOFF §10の棄権エンコーディング残課題は「0は事実上未使用、+1/-1の二値」として暫定確定（様子見方針どおり）。

## パイロット行列の記述統計（2024Q2 + 2025Q2、参考値）

- 規模: **3社 × 33,260議案（3,093総会）、観測89,855セル**、矛盾重複0件。
- 3社全員が投票した議案: 26,404。うち**賛否が割れた議案: 4,794（18.2%）** — 識別に使える変動が実在する。
- ペア一致率（共通観測列上）: アモーヴァ×MUFG信託 85.7% / アモーヴァ×ニッセイ 90.3% / MUFG信託×ニッセイ 86.8%。
- 反対率: アモーヴァ 15.1% / MUFG信託 16.6% / ニッセイ 12.9%。
- FactorModel煙テスト（lopsided除去後 3×5,545、k=1）: パイプラインは動作。**N=3ではEM反復が200回で未収束**（想定内 — 行数3の行列では補完が不安定。スケール段階でN≥10前後になれば解消見込み。この数値は主張に使わない）。
